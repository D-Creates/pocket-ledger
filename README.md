# Pocket Ledger

Pocket Ledger — a private, offline budget ledger for macOS, iPhone and Apple Watch. Accounts, transactions, budgets, charts, CSV export. No account, no tracking, no network.

- Web page: https://dcreations.fr/pocket-ledger/
- Privacy: https://dcreations.fr/pocket-ledger/privacy/ (the app collects no data)
- Releases: see the Releases page of this repo. The newest is marked "Latest"; older versions stay available.

## Build
1. Install Xcode 26 and XcodeGen (`brew install xcodegen`).
2. Run `xcodegen generate` in this folder.
3. Open the generated project, set your own signing team, and run.
